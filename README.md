# Manufacturing Analytics Dashboard

## Project Overview
This project analyzes manufacturing data to monitor production performance, machine efficiency and product quality using data analytics tools.

## Tools Used
- **Excel:** Data cleaning, analysis and dashboard creation
- **SQL (MySQL):** Data querying and KPI calculations
- **Power BI:** Interactive dashboard visualization
- **Tableau:** Data visualization and analysis

## Key KPIs
- Total Orders
- Total Manufactured Quantity
- Total Processed Quantity
- Efficiency Rate (%)
- Machine Utilization (%)
- Cost per Unit
- Rejection Rate (%)

## Key Insights
- Compared ordered, processed, and produced quantities.
- Identified top-performing machines by production quantity.
- Analyzed production across buyers, departments, and operations.
- Evaluated rejected quantities and rejection rates to monitor product quality.

## Objective
To transform manufacturing data into meaningful insights that support production monitoring, operational efficiency and quality improvement.
